# Gerenciador de Tarefas

Projeto de estudo para praticar desenvolvimento back end com Java. A ideia é construir um sistema de tarefas com cadastro de usuários e CRUD completo, passo a passo, e documentar o que eu for aprendendo no caminho.

## Funcionalidades planejadas
- [ ] Cadastro de usuários
- [ ] Criar, listar, editar e excluir tarefas (CRUD)
- [ ] Status da tarefa (pendente, em andamento, concluída)
- [ ] Tarefas associadas a cada usuário
- [ ] Interface simples

## Tecnologias
- Java 21
- Spring Boot (Web, Data JPA, Validation)
- PostgreSQL
- Maven
- Git e GitHub

Em desenvolvimento. Hoje o projeto já compila e conecta ao banco de dados; as entidades e as rotas ainda estão serao disponibilizadas
